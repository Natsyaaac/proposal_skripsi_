Rancang Bangun
Sistem Informasi
Penerimaan Murid Baru (SPMB), termasuk dasar istilah SPMB untuk madrasah
Pengelolaan Data Peserta Didik
Fitur sistem, dikelompokkan supaya tiap subbab tidak terlalu tipis teorinya:
Pendaftaran daring dan luring
Unggah dan verifikasi kelengkapan berkas
Notifikasi WhatsApp (WhatsApp API)
Pembagian kelas dan ekspor data (Excel/CSV)
Website
Perangkat pengembangan: TypeScript, Next.js, Supabase, Vercel, GitHub dan GitHub Actions, VS Code
Metode Waterfall (diuraikan lebih dalam daripada di Bab I)
Alat perancangan sistem: Flowchart, ERD, UML, Diagram Aktivitas, Bagan Alir Dokumen, Mockup
Pengujian: Black Box Testing dan Playwright
